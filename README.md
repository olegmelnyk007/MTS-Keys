# MTS Keys

A responsive one-page website starter for an automotive locksmith business.

## Customize before publishing

- Replace `[Your Service Area]` with the cities or region you serve.
- Replace `(555) 555-0100` and `+15555550100` with your business phone number.
- Update the service descriptions to match the services you actually offer.
- Add your business hours, email, and any required licensing details.

## Preview

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `mts-keys`.
2. Add `index.html`, `styles.css`, and `README.md` to the repository.
3. In the repository settings, open **Pages**.
4. Choose the `main` branch and root folder as the publishing source.
5. Save; GitHub will show the published site address in the Pages settings.
